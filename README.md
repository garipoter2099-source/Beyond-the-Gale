# Beyond the Gale - Мультиплеерная игра на Unity

## Описание проекта
Бeyond the Gale - это мультиплеерная онлайн-игра, где игроки управляют специальными машинами для перехвата торнадо, зарабатывают деньги и развивают свои компании.

## Основные функции
- Сервер-авторитетная архитектура с Netcode for GameObjects
- Динамический спавн торнадо 7 категорий (EFU - EF5)
- Система компаний с ролями и рейтингами
- Система улучшений оборудования
- Мультиплеерный чат в реальном времени
- Синхронизированная физика машин

## Требования
- Unity 2022.3+
- Netcode for GameObjects
- Mirror (альтернатива)

## Установка
1. Клонировать репозиторий
2. Открыть проект в Unity
3. Установить зависимости через Package Manager
4. Запустить сцену `SplashScreen`
